Las notas, las descripciones de tareas y las de proyectos se ven en un editor con formato. Escríbelas organizadas, nunca como un bloque de texto corrido.

**Formato que se convierte solo**
- `## Título` y `### Subtítulo` para separar secciones.
- `**negrita**` para datos clave (fechas, montos, nombres), `*cursiva*` para matices.
- `==resaltado==` (amarillo) solo para lo más importante o un riesgo.
- `~~tachado~~` para lo descartado.
- Listas con `- ` y pasos numerados con `1. `.
- Casillas con `- [ ] pendiente` y `- [x] hecho` para checklists.
- `> cita` para una referencia o una frase textual.
- `---` en una línea sola como separador entre bloques.
- Enlaces como `[Video de referencia](https://...)`; también sirve la URL suelta.

**Cómo organizar**
- Empieza con una línea de resumen y luego secciones con `##`.
- Una idea por viñeta, frases cortas. Nada de párrafos de más de 3 líneas.
- Agrupa siempre igual: qué es, referencias, cómo se hace, checklist, riesgos.
- Si hay varios ítems paralelos (por ejemplo dos videos), usa un `##` por ítem y `---` entre ellos.

**Ejemplo (descripción de una tarea de videos)**
```
## Video 1 · El espadero entra al corrido
Planos reales del taller que terminan en una transformación con IA.

**Tendencia:** Bulin 47 con IA
- Referencia: [búsqueda en TikTok](https://www.tiktok.com/search?q=Bulin%2047%20IA)
- Audio: instrumental de corrido con licencia

### Producción
1. Grabar manos, acero y forja (8 s).
2. Transición a personaje con IA (5 s).

### Checklist
- [ ] Guion del gancho
- [ ] Grabación en taller
- [ ] Edición y subtítulos

==Riesgo: no usar la cara ni la voz del artista real.==
```
